# GeoKameral — демо веб-интерфейса

Демонстрация интерфейса сервиса камеральной обработки геодезических данных (ЛиДАР, аэрофотосъёмка с БПЛА)
по нормам Республики Казахстан.

**Открыть:** https://aslanraskeldinov-glitch.github.io/geokameral-demo/

В демо:
- справочник систем координат РК (QazTRF-23, СК-42, 60 МСК по приказу МЦРИАП № 520/НҚ);
- результаты тестовой задачи ЛиДАР (ЦМР, ЦМП, топоплан DXF 1:500, 3D-модель, классифицированное облако) — файлы скачиваются;
- калибровка по пунктам и контроль точности по Инструкции № 113/НҚ (п. 51–52) — расчёт в браузере,
  пример файла: [data/control_points_example.csv](data/control_points_example.csv).

Обработка новых данных и агент-камеральщик работают только в полной версии на сервере компании.
